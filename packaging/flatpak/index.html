Timezones

World clocks for GNOME: one row per city on a shared timeline.

Install with Flatpak

Open @APP_ID@.flatpakref with GNOME Software, or run:

flatpak install --user @URL@/@APP_ID@.flatpakref

Updates then arrive through flatpak update and GNOME Software. The GNOME runtime comes from Flathub, which is added automatically if missing.

Other ways to install

  • Fedora: sudo dnf copr enable hernantz/timezones && sudo dnf install timezones
  • Arch Linux: timezones from the AUR
  • A .flatpak file on the releases page
